Muddy scrap pile fragments can be hard to see. This mod highlights them.

Note: The highlight is only active while inside a Sunken Crypt. Outside, no piles are tracked, no
shells or markers are drawn, and no scanning is performed.

# Installation

This mod is client-side only. You do not need to install it on the server.

## Using a mod manager (recommended)

You can install the mod using Vortex or Gale.

## Manual

Install BepInExPack for Valheim. Copy the DLL file to
`Steam\steamapps\common\Valheim\BepInEx\plugins\`

# Configuration

`BepInEx\config\orax.MuddyScrapPileHighlight.cfg` - every entry is read live, so a change applies at
once, without a restart.
